# Azure App Service and Azure Functions

## 1. What is Azure App Service?
Azure App Service is a platform for hosting web apps, APIs, and backend services.

## 2. What is Azure Functions?
Azure Functions is a serverless compute service for running small event-driven pieces of code.

## 3. Common use cases
- REST APIs
- background jobs
- file processing
- event-driven automation

## 4. Practical implementation steps
### App Service
1. Create a web app in Azure Portal
2. Deploy a simple Node.js or Python app
3. Test the public URL

### Functions
1. Create a Function App
2. Add an HTTP-triggered function
3. Test with sample input

## 5. Interview-focused understanding
You should be able to explain when to choose App Service versus Functions.
