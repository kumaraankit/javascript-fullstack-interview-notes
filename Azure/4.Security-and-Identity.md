# Security and Identity in Azure

## 1. What is Azure Identity?
Azure Identity helps services and applications authenticate users and resources securely.

## 2. What is Azure Key Vault?
Azure Key Vault is used to store secrets, keys, and certificates securely.

## 3. What is Managed Identity?
Managed Identity lets Azure resources authenticate to other Azure services without storing passwords.

## 4. Practical implementation steps
1. Create a Key Vault
2. Store a secret
3. Access it from an app using managed identity
4. Avoid hardcoding secrets in code

## 5. Why this matters
Security is a major part of modern backend systems and exam scenarios.
