# Azure Foundations

## 1. What is Azure?
Azure is Microsoft’s cloud computing platform that provides services for compute, data, networking, AI, and security.

## 2. Core Azure concepts
- Subscription
- Resource Group
- Resource
- Region
- Availability Zone

## 3. Why Azure matters for developers
Azure helps developers deploy scalable apps, manage secrets, connect services, and monitor performance.

## 4. Practical steps to get good hold
- Create a free Azure account
- Explore the portal
- Create a resource group
- Deploy a simple web app
- Practice deleting and recreating resources
