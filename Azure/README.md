# Azure Developer Associate (AZ-204) Study Hub

This section is created to help you build practical Azure skills for backend and cloud-based development.

## Focus Areas
- Azure App Service
- Azure Functions
- Cosmos DB
- Azure Storage
- Azure Service Bus
- Azure Key Vault
- Azure Identity and Authentication
- API Management
- Monitoring and Logging
- Containers and Docker

## Recommended Learning Path
1. Start with core Azure concepts and resource models.
2. Learn Azure App Service and Functions.
3. Work with storage, databases, and messaging.
4. Practice authentication and secure configuration.
5. Build small end-to-end apps and deploy them.
6. Prepare for exam scenarios using hands-on labs.

## Best Way to Get Good Hold
- Build one small app each week
- Use the Azure portal and CLI regularly
- Read the docs for one service at a time
- Practice deploying and troubleshooting real resources
- Focus on scenarios, not only definitions
- Use official Microsoft documentation as your primary learning source
