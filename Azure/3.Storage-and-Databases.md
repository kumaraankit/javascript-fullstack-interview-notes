# Azure Storage and Databases

## 1. What Azure storage services are commonly used?
- Azure Blob Storage
- Azure Table Storage
- Azure Queue Storage
- Azure Files

## 2. What is Cosmos DB?
Cosmos DB is a globally distributed NoSQL database service.

## 3. What is Azure SQL Database?
Azure SQL Database is a managed relational database service.

## 4. Practical implementation steps
### Blob Storage
1. Create a storage account
2. Create a container
3. Upload a file
4. Retrieve the file URL

### Cosmos DB
1. Create an Azure Cosmos DB account
2. Create a database and container
3. Insert sample documents
4. Query them from code

## 5. Interview-focused understanding
You should be able to explain trade-offs among Blob Storage, Cosmos DB, and SQL Database.
