# Monitoring, Logging, and Deployment

## 1. What is Azure Monitor?
Azure Monitor provides observability for applications, infrastructure, and services.

## 2. What is Application Insights?
Application Insights is used for telemetry, logging, and performance monitoring.

## 3. Practical implementation steps
1. Enable Application Insights in an app service
2. Send logs from your app
3. View request and exception metrics
4. Use alerts for failures or latency spikes

## 4. Why this matters
Production systems depend heavily on monitoring and diagnostics.
