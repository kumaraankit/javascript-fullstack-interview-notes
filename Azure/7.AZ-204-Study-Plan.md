# AZ-204 Study Plan

## How to get a strong hold on AZ-204

### 1. Learn by building
Do not only read theory. Build small projects in Azure.

### 2. Focus on hands-on services
Prioritize these services:
- App Service
- Functions
- Storage
- Cosmos DB
- Service Bus
- Key Vault
- Application Insights

### 3. Practice the common exam patterns
Be ready to explain:
- when to use App Service vs Functions
- how to secure secrets
- how to connect services
- how to monitor applications
- how to choose storage options

### 4. Recommended weekly plan
- Week 1: Azure basics, portal, resource groups
- Week 2: App Service and Functions
- Week 3: Storage, Cosmos DB, and SQL
- Week 4: Security, Key Vault, and identity
- Week 5: Service Bus, API Management, and monitoring
- Week 6: Build mini projects and revise

### 5. Best practical habit
Every week, build one small app or deploy one service to Azure and document what you learned.
