# Hugging Face Basics

## 1. What is Hugging Face?
Hugging Face provides a large ecosystem for working with machine learning models, especially transformers.

## 2. Why is it important?
It makes it easy to load, run, and fine-tune state-of-the-art models.

## 3. Common tools
- transformers
- datasets
- pipelines
- accelerate

## 4. Example concept
You can use a text classification pipeline in a few lines of Python.
