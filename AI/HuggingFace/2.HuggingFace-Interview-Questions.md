# Hugging Face Interview Questions

## 1. What is Hugging Face?
Hugging Face is a platform and ecosystem for machine learning models, datasets, and tools.

## 2. Why is Hugging Face popular?
It provides easy access to state-of-the-art models and supporting libraries.

## 3. What are common Hugging Face libraries?
`transformers`, `datasets`, and `pipelines`.

## 4. What is a pipeline?
A pipeline is a high-level API for common NLP tasks.

## 5. What is a common use case?
Text classification, summarization, translation, and question answering.
