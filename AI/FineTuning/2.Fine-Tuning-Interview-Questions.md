# Fine-Tuning Interview Questions

## 1. What is fine-tuning?
Fine-tuning adapts a pre-trained model to a new domain or task using additional labeled data.

## 2. When should you fine-tune a model?
When prompt engineering is insufficient and you need better task-specific performance.

## 3. What are common challenges?
Data quality, overfitting, and hardware cost.

## 4. What are common fine-tuning use cases?
Classification, summarization, chat assistants, and code generation.

## 5. What is a major trade-off?
Fine-tuning can improve quality but requires more time and compute.
