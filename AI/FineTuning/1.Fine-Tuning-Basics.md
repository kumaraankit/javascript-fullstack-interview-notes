# Fine-Tuning Basics

## 1. What is fine-tuning?
Fine-tuning updates a pre-trained model using task-specific examples so it performs better for a target use case.

## 2. When should you fine-tune?
Use fine-tuning when you need better domain-specific responses and your task is not well covered by prompt engineering alone.

## 3. Common use cases
- domain-specific chatbots
- classification tasks
- summarization
- code generation

## 4. Important trade-offs
- requires data
- more cost and compute
- may overfit if the dataset is small
