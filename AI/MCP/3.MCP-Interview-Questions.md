# MCP Interview Questions

## 1. What is MCP?
MCP is a protocol that gives AI systems a standardized way to access tools and resources.

## 2. Why is MCP useful?
It helps connect AI agents to tools in a consistent and modular way.

## 3. What is an MCP server?
An MCP server exposes capabilities such as tools, prompts, and resources to an AI client.

## 4. What is a common use case for MCP?
A database query tool, file tool, or internal API integration.

## 5. How would you design an MCP server?
You would define clear tools, input schemas, authentication, and structured responses.
