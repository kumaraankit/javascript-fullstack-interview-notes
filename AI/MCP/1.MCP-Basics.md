# MCP Basics

## 1. What is MCP?
MCP stands for Model Context Protocol. It provides a structured way for AI applications to connect to tools, resources, and external systems.

## 2. Why is MCP important?
It helps avoid hardcoded integrations and makes AI systems more modular, interoperable, and scalable.

## 3. Core idea
MCP allows an AI agent to discover capabilities and use them consistently through a common interface.

## 4. Example concept
An AI assistant can use:
- a file system tool
- a web search tool
- a database tool
- a calendar tool

All of them can be exposed through MCP-compatible interfaces.
