# Building MCP Servers

## 1. What is an MCP server?
An MCP server exposes capabilities such as tools, prompts, or resources to an AI client.

## 2. Typical server responsibilities
- expose tools
- accept requests from clients
- perform actions such as file access or API calls
- return structured results

## 3. Why build one?
You build an MCP server when you want your AI application to use your own services or internal systems safely and consistently.

## 4. Simple architecture
Client -> MCP Server -> Tool/Service -> Response

## 5. Common use cases
- internal knowledge base access
- code search tools
- database querying
- workflow automation
