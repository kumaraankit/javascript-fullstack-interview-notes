# CrewAI Basics

## 1. What is CrewAI?
CrewAI is used to coordinate multiple AI agents, each with a role, goal, and set of tools.

## 2. Why use it?
It is useful for multi-step tasks that benefit from specialization and collaboration.

## 3. Typical example
A research crew may include:
- researcher agent
- writer agent
- reviewer agent

## 4. Core pattern
Task -> Agent -> Result -> Next agent
