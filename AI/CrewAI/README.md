# CrewAI

## What is CrewAI?
CrewAI is a framework for orchestrating multiple AI agents that collaborate on tasks.

## Topics
- Agent roles
- Task delegation
- Collaboration patterns
- Multi-agent workflows
- Production considerations

## Learning Flow
1. Learn the concept of roles and tasks
2. Create a simple crew
3. Add collaboration and shared memory
4. Build a practical multi-agent workflow
