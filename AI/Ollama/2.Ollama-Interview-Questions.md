# Ollama Interview Questions

## 1. What is Ollama?
Ollama is used to run open-source LLMs locally on your machine.

## 2. Why would someone use Ollama?
For privacy, offline use, low-cost experimentation, and local development.

## 3. What is a common command to run a model?
```bash
ollama run llama3
```

## 4. What is a common use case?
Local chatbot development or private AI prototypes.

## 5. What is a benefit of local inference?
Less dependency on cloud services during development.
