# Ollama Basics

## 1. What is Ollama?
Ollama is a tool for running open-source LLMs locally.

## 2. Why use Ollama?
It helps with privacy, offline experimentation, and lower-cost prototyping.

## 3. Typical use cases
- local chat assistant
- offline development
- model testing
- private AI prototypes

## 4. Example command
```bash
ollama run llama3
```
