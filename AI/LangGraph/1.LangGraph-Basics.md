# LangGraph Basics

## 1. What is LangGraph?
LangGraph helps you model workflows as graphs where nodes represent steps and edges represent transitions.

## 2. Why use it?
It is useful for building agents and workflows that need memory, branching, retries, and step-by-step control.

## 3. Core idea
A workflow moves through states and can branch based on conditions or tool results.

## 4. Example use case
A research agent can:
1. collect search results
2. rank them
3. summarize the top result
4. ask for confirmation if needed
