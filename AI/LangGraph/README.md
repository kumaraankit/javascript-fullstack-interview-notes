# LangGraph

## What is LangGraph?
LangGraph is used to build stateful, multi-step agent workflows with control flow and graph-based orchestration.

## Topics
- Graph concepts
- State management
- Nodes and edges
- Complex agent workflows
- Human-in-the-loop patterns

## Learning Flow
1. Learn graph basics
2. Build a simple workflow
3. Add decision branches
4. Implement state transitions
5. Deploy as an agent system
