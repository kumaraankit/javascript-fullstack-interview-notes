# LangGraph Interview Questions

## 1. What is LangGraph?
LangGraph is used to build stateful, graph-based workflows for agents and LLM applications.

## 2. Why use LangGraph instead of a simple chain?
It is better for branching, loops, retries, and stateful workflows.

## 3. What is a node in LangGraph?
A node is a step or action in the workflow.

## 4. What is an edge?
An edge is the transition from one node to another.

## 5. Where is LangGraph useful?
It is useful for multi-step agents, approval workflows, and planning systems.
