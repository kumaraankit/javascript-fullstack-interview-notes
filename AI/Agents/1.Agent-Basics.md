# Agent Basics

## 1. What is an AI agent?
An AI agent is a program that uses an LLM to interpret instructions, choose actions, and perform tasks.

## 2. Core components
- model
- prompts
- tools
- memory
- execution loop

## 3. Simple agent flow
User request -> LLM reasoning -> tool call -> result -> final response

## 4. Example use cases
- customer support agent
- coding assistant
- research assistant
- workflow automation bot
