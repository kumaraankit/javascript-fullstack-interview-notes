# AI Agents

## What is an AI agent?
An AI agent is a system that can reason over a task, decide which tools to use, and act autonomously.

## Topics
- Agent basics
- Tool calling
- Planning and reasoning
- Memory and state
- Multi-agent systems

## Learning Flow
1. Understand single-agent behavior
2. Connect tools and functions
3. Add memory and state
4. Build a multi-agent workflow
5. Deploy with APIs or UIs
