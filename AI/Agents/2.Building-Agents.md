# Building Agents

## 1. What makes an agent useful?
An agent becomes useful when it can interact with tools, handle context, and recover from failure.

## 2. Important design decisions
- what tools it can use
- how it handles memory
- how it validates outputs
- how it handles retries

## 3. Common patterns
- single-agent workflow
- tool-augmented agent
- planner-executor pattern
- multi-agent collaboration

## 4. Best practices
- keep tools narrow and well-defined
- avoid too much autonomy without guardrails
- log agent actions for debugging
