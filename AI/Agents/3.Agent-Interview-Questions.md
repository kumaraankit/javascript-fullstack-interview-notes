# Agent Interview Questions

## 1. What is an AI agent?
An AI agent is a system that can interpret user intent, choose actions, and use tools to complete a task.

## 2. What are the main components of an agent?
A model, prompt, tools, memory, and execution loop.

## 3. Why is tool use important?
Tools allow agents to interact with external systems and perform real actions.

## 4. What is the difference between a chatbot and an agent?
A chatbot mainly responds, while an agent can take actions and use tools.

## 5. What is a good design principle for agents?
Keep tools small, clear, and safe, and avoid over-automation.

## Code Example
```python
from typing import List

class Agent:
    def __init__(self, name: str, tools: List[str]):
        self.name = name
        self.tools = tools

    def run(self, task: str):
        return f"{self.name} is handling: {task}"
```
