# LangChain Interview Questions

## 1. What is LangChain?
LangChain is a framework for composing LLM workflows using prompts, tools, memory, and chains.

## 2. What are chains?
Chains connect multiple steps into one workflow.

## 3. What is a prompt template?
A prompt template structures model input in a reusable way.

## 4. What is memory in LangChain?
Memory stores prior context to improve conversational behavior.

## 5. What are agents in LangChain?
Agents let the model choose tools dynamically based on the task.

## Code Example
```python
from langchain.prompts import PromptTemplate

prompt = PromptTemplate(template="Summarize this: {text}", input_variables=["text"])
print(prompt.format(text="Hello world"))
```
