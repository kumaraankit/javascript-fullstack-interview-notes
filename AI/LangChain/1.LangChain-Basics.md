# LangChain Basics

## 1. What is LangChain?
LangChain helps developers connect LLMs with data, tools, and workflows in a structured way.

## 2. Core building blocks
- prompt templates
- models
- chains
- tools
- memory
- agents

## 3. Why use it?
It simplifies the development of LLM-based applications and reduces boilerplate.

## 4. Example idea
Use an LLM to answer questions from a document store or connect to an API.
