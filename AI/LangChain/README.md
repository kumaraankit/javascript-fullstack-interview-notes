# LangChain

## What is LangChain?
LangChain is a framework for building applications with LLMs using chains, prompts, tools, memory, and agents.

## Topics
- Basics
- Prompt templates
- Chains
- Tools and agents
- Retrieval and memory
- Production patterns

## Learning Flow
1. Understand core abstractions
2. Build simple chains
3. Add tools and memory
4. Build retrieval-based apps
5. Deploy in production
