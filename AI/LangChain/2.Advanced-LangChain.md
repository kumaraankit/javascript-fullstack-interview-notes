# Advanced LangChain Concepts

## 1. What are chains?
Chains combine multiple steps such as prompt execution, retrieval, and tool use into one workflow.

## 2. What is memory?
Memory allows an app to remember previous parts of a conversation or previous interactions.

## 3. What are retrievers?
Retrievers fetch relevant information from documents or vectors before prompting the model.

## 4. What are agents in LangChain?
Agents allow the model to decide which tool to use based on the current task.

## 5. Production concerns
- latency
- prompt quality
- tool reliability
- observability
- cost control
