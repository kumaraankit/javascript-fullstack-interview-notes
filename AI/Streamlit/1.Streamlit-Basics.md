# Streamlit Basics

## 1. What is Streamlit?
Streamlit is a Python framework that allows you to turn scripts into interactive web applications quickly.

## 2. Why use it?
It is ideal for AI demos, dashboards, and prototypes.

## 3. Common features
- text input
- buttons
- sliders
- charts
- file upload

## 4. Example use case
Build a local chatbot UI that sends prompts to an LLM.
