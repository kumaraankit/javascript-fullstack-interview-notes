# Streamlit Interview Questions

## 1. What is Streamlit?
Streamlit is a Python library for building interactive web apps for AI demos and dashboards.

## 2. Why is it useful for AI projects?
It allows fast prototyping without needing frontend expertise.

## 3. What are common Streamlit components?
Buttons, sliders, text inputs, file uploaders, and charts.

## 4. What is a typical AI app built with Streamlit?
A chatbot UI, document Q&A app, or dashboard over model outputs.

## 5. What is the main advantage?
Rapid development and easy iteration.
