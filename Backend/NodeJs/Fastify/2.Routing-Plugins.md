# Routing and Plugins – Fastify Interview Guide

This page focuses on routing design, plugin architecture, and hook-based execution.

---

## 6. How does routing work in Fastify?

Routing in Fastify is simple and expressive. You can define routes with methods such as `get`, `post`, `put`, and `delete`.

```js
fastify.get('/users/:id', async (request) => {
  return { id: request.params.id };
});
```

### Senior insight
Route definitions should stay small, and business logic should be delegated to services or handlers.

---

## 7. What is a Fastify plugin?

A plugin is a reusable unit that registers routes, decorators, hooks, or other Fastify features. Plugins are one of the core reasons Fastify scales well.

```js
async function userPlugin(fastify) {
  fastify.get('/profile', async () => ({ ok: true }));
}

fastify.register(userPlugin);
```

### Why plugins matter
- Encapsulate features
- Improve maintainability
- Avoid global side effects

---

## 8. What are hooks in Fastify?

Hooks are lifecycle functions that let you run logic at specific stages of request processing.

Examples:
- `onRequest`
- `preValidation`
- `preHandler`
- `onSend`
- `onResponse`

```js
fastify.addHook('preHandler', async (request, reply) => {
  request.user = { id: 1 };
});
```

### Senior perspective
Hooks are powerful, but should be used carefully to avoid hidden behavior and debugging complexity.

---

## 9. How do you organize a large Fastify application?

A senior engineer usually splits the app into feature-based plugins and services. For example:
- `auth` plugin
- `users` plugin
- `orders` plugin
- `database` plugin

### Best practice
Keep route registration, validation, and business logic separate.

---

## 10. What is encapsulation in Fastify?

Encapsulation means a plugin can have its own scope for decorators, hooks, and routes. This prevents accidental collisions between features.

### Why it is important
It makes large systems safer and more modular. It also makes plugin reuse more predictable.

---

## Interview takeaway
Good Fastify architecture is based on plugins, hooks, and encapsulation rather than a single large server file.
