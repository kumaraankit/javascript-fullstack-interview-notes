# Testing and Deployment – Fastify Interview Guide

This page is about how senior engineers test and deploy Fastify services.

---

## 26. How do you test Fastify routes?

Fastify applications can be tested using Node test runners or libraries such as `supertest` or `tap`.

```js
const fastify = require('fastify')();

fastify.get('/ping', async () => ({ ok: true }));
```

### Senior view
Tests should verify behavior, not just that a route exists.

---

## 27. Why is testing important in Fastify applications?

Testing ensures:
- contract stability
- regression prevention
- safer refactoring
- confidence during deployment

---

## 28. How would you structure tests for a Fastify service?

A good structure usually includes:
- unit tests for services
- integration tests for routes and plugins
- end-to-end tests for workflows

### Senior guidance
Use realistic test data and keep test setup simple.

---

## 29. How do you deploy a Fastify app?

Fastify apps are commonly deployed using Docker, Kubernetes, or platform services such as Render, Railway, Vercel for serverless-compatible patterns, or cloud VMs.

### Best practice
Use environment-based configuration and include health checks in deployment pipelines.

---

## 30. What are the key production concerns for Fastify services?

- Graceful shutdown
- Proper logging
- Metrics collection
- Resource limits
- Error monitoring
- Scaling strategy

### Senior perspective
Production readiness is about reliability and operability, not just code correctness.

---

## Interview takeaway
A senior Fastify engineer builds services that are testable, observable, and deployment-friendly from the beginning.
