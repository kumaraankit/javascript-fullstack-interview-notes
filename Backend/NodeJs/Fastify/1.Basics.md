# Fastify Basics – Senior Interview Guide

This page covers the first set of Fastify interview questions for backend engineers.

---

## 1. What is Fastify?

Fastify is a high-performance Node.js web framework for building APIs and web applications. It is known for its low overhead, schema-based validation, and plugin architecture.

### Why it is popular
- Very fast request handling
- Great developer experience
- Built-in support for validation and serialization
- Strong plugin-based architecture

### Basic example
```js
const fastify = require('fastify')();

fastify.get('/health', async () => ({ status: 'ok' }));

fastify.listen({ port: 3000 });
```

---

## 2. Why is Fastify preferred over Express in many modern APIs?

Fastify is often chosen when performance and structure matter. It provides better throughput, lower overhead, and a schema-first approach, which reduces runtime surprises.

### Key reasons
- Smaller runtime overhead
- Built-in validation and serialization
- Better plugin encapsulation
- Strong ecosystem for production APIs

---

## 3. What is the request lifecycle in Fastify?

Fastify executes hooks and handlers in a predictable order. A typical lifecycle is:

1. `onRequest`
2. `preParsing`
3. `parsing`
4. `preValidation`
5. `validation`
6. `preHandler`
7. `handler`
8. `onSend`
9. `onResponse`

### Why this matters
It helps engineers place authentication, validation, logging, and transformation logic in the correct stage.

---

## 4. How do you create a Fastify server?

You create an instance with `fastify()` and register routes or plugins.

```js
const fastify = require('fastify')({ logger: true });

fastify.get('/', async (request, reply) => {
  return { message: 'Hello Fastify' };
});
```

### Senior insight
A good Fastify server is modular, uses plugins, and keeps route logic thin.

---

## 5. What are decorators in Fastify?

Decorators allow you to attach reusable properties and methods to the Fastify instance, request, or reply objects.

```js
fastify.decorate('greet', function (name) {
  return `Hello ${name}`;
});
```

### Why this is useful
It helps centralize shared logic without creating a lot of duplicated helpers.

---

## Interview takeaway
Fastify is not just a faster Express-like framework. It is a schema-driven, plugin-oriented framework that encourages cleaner and more scalable API design.
