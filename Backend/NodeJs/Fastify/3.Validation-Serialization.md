# Validation and Serialization – Fastify Interview Guide

This page covers schema-driven validation and response serialization, which are major strengths of Fastify.

---

## 11. What is schema-based validation in Fastify?

Fastify allows you to attach JSON schemas to routes. These schemas are used for request validation and response serialization.

```js
fastify.post('/users', {
  schema: {
    body: {
      type: 'object',
      required: ['name'],
      properties: {
        name: { type: 'string' }
      }
    }
  }
}, async (request) => {
  return { ok: true };
});
```

### Why this is helpful
It makes APIs safer and improves consistency.

---

## 12. Why does Fastify use AJV internally?

Fastify uses AJV for fast and efficient validation. This helps reduce the cost of manual checks and supports better runtime guarantees.

### Senior insight
Schema validation should be treated as a first-class API contract, not an afterthought.

---

## 13. What is response serialization in Fastify?

Serialization ensures that the final response shape is clean and predictable before it is sent to the client.

```js
fastify.get('/user', {
  schema: {
    response: {
      200: {
        type: 'object',
        properties: {
          id: { type: 'number' },
          name: { type: 'string' }
        }
      }
    }
  }
}, async () => ({ id: 1, name: 'Ankit' }));
```

### Why it matters
It improves performance and prevents accidental data leakage.

---

## 14. How do you handle errors in Fastify?

Fastify supports custom error handlers through `setErrorHandler`.

```js
fastify.setErrorHandler((error, request, reply) => {
  reply.code(500).send({ error: error.message });
});
```

### Senior guidance
Errors should be normalized, logged, and returned with a consistent shape.

---

## 15. What are the best practices for validation in Fastify?

- Define schemas for body, params, and query
- Use `required`, `type`, and `additionalProperties`
- Avoid over-validation
- Use `stripUnknown: true` when appropriate

### Why
This keeps your API secure, predictable, and easier to maintain.

---

## Interview takeaway
Schema-driven validation and serialization make Fastify an excellent choice for enterprise-grade APIs.
