# Async Programming in Python

## 22. What is asynchronous programming?
Asynchronous programming allows code to perform non-blocking operations efficiently, which is useful for I/O-bound tasks.

### Example with `async` and `await`
```python
import asyncio

async def main():
    print("Hello")
    await asyncio.sleep(1)
    print("World")

asyncio.run(main())
```

---

## 23. What is the difference between multiprocessing and multithreading?
- Multithreading is useful for I/O-bound work.
- Multiprocessing is useful for CPU-bound work and uses separate processes.

---

## 24. What is the Global Interpreter Lock (GIL)?
The GIL is a mutex in CPython that prevents multiple native threads from executing Python bytecode at once. It affects CPU-bound multithreading performance.
