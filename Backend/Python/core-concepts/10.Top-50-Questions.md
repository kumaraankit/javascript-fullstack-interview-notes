# Top 50 Python Interview Questions

This page is designed for self-interview practice on Python, covering both beginner and intermediate concepts.

---

## 1. What is Python?
Python is a high-level, interpreted programming language known for readability, rapid development, and a large ecosystem.

## 2. What is the difference between Python 2 and Python 3?
Python 3 is the modern version and is the one used today. Python 2 is officially discontinued.

## 3. What is PEP 8?
PEP 8 is the style guide for Python code. It defines conventions for readability and consistency.

## 4. What are variables in Python?
Variables are names that store values in memory.

```python
x = 10
name = "Ankit"
```

## 5. What is the difference between a list and a tuple?
A list is mutable, while a tuple is immutable.

## 6. What is a dictionary in Python?
A dictionary stores data as key-value pairs.

```python
user = {"name": "Ankit", "age": 30}
```

## 7. What is a set?
A set stores unique values and is unordered.

## 8. What is slicing?
Slicing extracts a portion of a sequence.

```python
text = "python"
print(text[0:3])
```

## 9. What is the difference between `==` and `is`?
`==` checks value equality, while `is` checks identity (whether two references point to the same object).

## 10. What is a function?
A function is a reusable block of code.

```python
def greet(name):
    return f"Hello {name}"
```

## 11. What are default arguments in Python?
Default arguments provide fallback values when the caller does not pass them.

```python
def greet(name="User"):
    return f"Hello {name}"
```

## 12. What is `*args` and `**kwargs`?
`*args` collects extra positional arguments, and `**kwargs` collects extra keyword arguments.

## 13. What is a lambda function?
A lambda function is an anonymous inline function.

```python
square = lambda x: x * x
```

## 14. What is a module?
A module is a Python file containing reusable code.

## 15. What is a package?
A package is a directory of related modules.

## 16. What is the difference between `import` and `from ... import`?
`import` imports the whole module, while `from ... import` imports specific members from it.

## 17. What is object-oriented programming?
OOP organizes code into classes and objects.

## 18. What is a class?
A class is a blueprint for creating objects.

## 19. What is an object?
An object is an instance of a class.

## 20. What is inheritance?
Inheritance lets a class reuse properties and methods from another class.

## 21. What is polymorphism?
Polymorphism allows different objects to respond to the same interface in different ways.

## 22. What is encapsulation?
Encapsulation restricts direct access to data and exposes controlled interfaces.

## 23. What is exception handling?
Exception handling allows code to manage runtime errors gracefully.

```python
try:
    10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
```

## 24. What is the difference between `try`, `except`, and `finally`?
`try` contains code that may fail, `except` handles the error, and `finally` always runs.

## 25. What is file handling in Python?
File handling allows reading from and writing to files.

```python
with open("file.txt", "r") as f:
    print(f.read())
```

## 26. What is `with open()` used for?
It ensures that the file is properly closed after use.

## 27. What is list comprehension?
List comprehension provides a concise way to create lists.

```python
squares = [x * x for x in range(5)]
```

## 28. What is a generator?
A generator yields values one at a time and is memory efficient.

```python
def gen():
    yield 1
    yield 2
```

## 29. What is the difference between a shallow copy and a deep copy?
A shallow copy copies the outer object, while a deep copy copies nested objects too.

## 30. What is `__init__`?
`__init__` is the constructor method that initializes object attributes.

## 31. What is `self` in Python?
`self` refers to the current instance of the class.

## 32. What is `__name__ == '__main__'`?
It is used to run code only when the file is executed directly.

## 33. What is `pass` in Python?
`pass` is a placeholder statement that does nothing.

## 34. What is `None` in Python?
`None` represents the absence of a value.

## 35. What is the difference between `range` and `xrange`?
In Python 3, `range` is used; in Python 2, `xrange` was used for memory efficiency.

## 36. What is the difference between `append()` and `extend()`?
`append()` adds one element, while `extend()` adds multiple elements.

## 37. What is `map()`?
`map()` applies a function to all elements in an iterable.

## 38. What is `filter()`?
`filter()` returns elements for which a function returns `True`.

## 39. What is `reduce()`?
`reduce()` combines elements into a single value.

## 40. What is the difference between `async` and `await`?
`async` defines an asynchronous function, and `await` pauses execution until a promise-like coroutine completes.

## 41. What is `asyncio`?
`asyncio` is Python’s library for writing asynchronous code.

## 42. What is the GIL?
The GIL is Python’s global interpreter lock, which affects multithreading performance for CPU-bound tasks.

## 43. What is virtualenv?
Virtualenv creates an isolated Python environment for dependencies.

## 44. What is `pip`?
`pip` installs and manages Python packages.

## 45. What is FastAPI?
FastAPI is a modern Python framework for building APIs quickly and efficiently.

## 46. What is Flask?
Flask is a lightweight web framework used for building web apps and APIs.

## 47. What is Django?
Django is a full-featured web framework with built-in tools for routing, ORM, and authentication.

## 48. What is SQLAlchemy?
SQLAlchemy is a database toolkit and ORM used in Python applications.

## 49. What is Pydantic?
Pydantic is used for data validation and type handling, especially with FastAPI.

## 50. How do you make Python code production-ready?
Use proper structure, tests, logging, error handling, configuration management, and clean architecture.

---

## Interview Tip
Practice answering these questions aloud. For senior roles, explain not only the definition but also the why and when behind each concept.
