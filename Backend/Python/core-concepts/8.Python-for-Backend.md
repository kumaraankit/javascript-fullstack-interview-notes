## 27. What is FastAPI and why is it popular?
FastAPI is a modern Python web framework for building APIs quickly. It supports async programming, type hints, and automatic validation.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}
```
