# Python Data Structures

## 4. What are lists, tuples, sets, and dictionaries?
These are built-in data structures in Python.

### List
A list is mutable and ordered.
```python
numbers = [1, 2, 3]
numbers.append(4)
```

### Tuple
A tuple is immutable and ordered.
```python
tags = ("python", "backend")
```

### Set
A set stores unique values.
```python
items = {1, 2, 2, 3}
```

### Dictionary
A dictionary stores key-value pairs.
```python
user = {"name": "Ankit", "age": 30}
```

---

## 5. What is the difference between list and tuple?
A list is mutable, while a tuple is immutable. Tuples are commonly used when you want fixed data.

## 6. What is slicing in Python?
Slicing allows you to extract a portion of a sequence.

```python
text = "python"
print(text[0:3])
```
