# Exceptions and File Handling

## 15. What is exception handling?
Exception handling allows the program to deal with runtime errors gracefully.

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
finally:
    print("Execution completed")
```

## 16. What is the difference between `open()` and `with open()`?
Using `with open()` ensures the file is properly closed after use.

```python
with open("file.txt", "r") as f:
    content = f.read()
```

## 17. What are common file modes in Python?
- `r` for reading
- `w` for writing
- `a` for appending
- `b` for binary mode
