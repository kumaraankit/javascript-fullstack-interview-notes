# Object-Oriented Programming in Python

## 11. What is OOP?
Object-Oriented Programming organizes code into objects that contain both data and behavior.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        return "woof"
```

---

## 12. What is inheritance?
Inheritance allows a class to reuse behavior from a parent class.

```python
class Animal:
    def speak(self):
        return "animal"

class Dog(Animal):
    def speak(self):
        return "bark"
```

---

## 13. What is polymorphism?
Polymorphism means different classes can implement the same interface in different ways.

---

## 14. What is encapsulation?
Encapsulation refers to restricting direct access to object data and exposing controlled interfaces.
