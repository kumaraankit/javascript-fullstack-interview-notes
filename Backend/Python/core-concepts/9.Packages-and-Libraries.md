# Python Packages and Libraries for Backend Development

This page covers commonly used Python packages and libraries that are important for backend and interview preparation.

---

## 1. What is a Python package?
A package is a collection of Python modules grouped together. It helps organize reusable code and makes dependency management easier.

Example:
```bash
pip install requests
```

---

## 2. What is `pip`?
`pip` is Python’s package installer. It is used to install, upgrade, and remove Python libraries.

```bash
pip install fastapi
pip install requests
pip install sqlalchemy
```

---

## 3. What is `requests` used for?
`requests` is used to make HTTP requests to external APIs and services.

```python
import requests

response = requests.get("https://jsonplaceholder.typicode.com/posts/1")
print(response.json())
```

---

## 4. What is `FastAPI` used for?
FastAPI is a modern web framework for building APIs with Python. It is known for speed, automatic validation, and async support.

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}
```

---

## 5. What is `Flask`?
Flask is a lightweight web framework for building APIs and web apps with minimal boilerplate.

```python
from flask import Flask

app = Flask(__name__)

@app.route("/health")
def health():
    return {"status": "ok"}
```

---

## 6. What is `Django`?
Django is a full-featured web framework that follows the “batteries included” philosophy. It includes ORM, authentication, admin, and routing.

---

## 7. What is `SQLAlchemy`?
SQLAlchemy is a powerful SQL toolkit and ORM for Python. It helps interact with databases in a Pythonic way.

```python
from sqlalchemy import create_engine

engine = create_engine("sqlite:///example.db")
```

---

## 8. What is `Pydantic`?
Pydantic is used for data validation and settings management. It is often used with FastAPI.

```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int
```

---

## 9. What is `pytest`?
`pytest` is a popular testing framework for Python.

```python
def test_add():
    assert 2 + 2 == 4
```

---

## 10. What is `uvicorn`?
Uvicorn is an ASGI server used to run FastAPI applications.

```bash
uvicorn main:app --reload
```

---

## 11. What is `redis-py`?
`redis-py` is a Python client for Redis, commonly used for caching and queues.

---

## 12. What is `celery`?
Celery is a distributed task queue for background job processing.

---

## 13. What is `numpy`?
NumPy is used for numerical computing and working with arrays efficiently.

---

## 14. What is `pandas`?
Pandas is widely used for data analysis and manipulation.

---

## 15. What is `beautifulsoup4`?
BeautifulSoup is used for parsing HTML and XML documents.

---

## 16. What is `asyncio`?
`asyncio` is Python’s built-in library for writing asynchronous code.

---

## 17. What is `python-dotenv`?
`python-dotenv` helps load environment variables from a `.env` file.

```python
from dotenv import load_dotenv
load_dotenv()
```

---

## 18. What is `psycopg2` or `psycopg`?
These are PostgreSQL database adapters for Python.

---

## 19. What is `httpx`?
`httpx` is a modern HTTP client with async support.

---

## 20. What is `gunicorn`?
Gunicorn is a WSGI HTTP server commonly used to deploy Flask or Django applications.

---

## Interview takeaway
A strong Python backend engineer should know not only the language syntax but also the most commonly used libraries for APIs, databases, testing, and deployment.
