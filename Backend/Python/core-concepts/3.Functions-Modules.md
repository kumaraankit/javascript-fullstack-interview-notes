# Functions and Modules

## 7. What is a function in Python?
A function is a reusable block of code that performs a specific task.

```python
def add(a, b):
    return a + b
```

---

## 8. What is the difference between `*args` and `**kwargs`?
- `*args` collects extra positional arguments.
- `**kwargs` collects extra keyword arguments.

```python
def demo(*args, **kwargs):
    print(args)
    print(kwargs)
```

---

## 9. What is a module?
A module is a Python file containing reusable code.

```python
import math
print(math.sqrt(16))
```

---

## 10. What is the difference between a package and a module?
A module is a single file, while a package is a collection of modules organized in a directory.
