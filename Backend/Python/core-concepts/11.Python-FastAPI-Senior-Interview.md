# Python + FastAPI – Senior Backend Interview Guide

This file is focused on senior-level interview preparation for Python backend engineers using FastAPI.

---

## 1. What is FastAPI?
FastAPI is a modern Python web framework for building APIs quickly. It is known for high performance, async support, automatic request validation, and built-in OpenAPI documentation.

---

## 2. Why is FastAPI popular for backend development?
FastAPI is popular because it offers:
- excellent developer experience
- automatic validation with Pydantic
- async support
- fast performance
- easy API documentation with Swagger and Redoc

---

## 3. How do you create a basic FastAPI app?

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/health")
def health():
    return {"status": "ok"}
```

---

## 4. What is dependency injection in FastAPI?
Dependency injection is a design pattern where dependencies such as database sessions, auth checks, or config values are provided to endpoints in a clean and reusable way.

```python
from fastapi import Depends, FastAPI

app = FastAPI()

def get_query(q: str | None = None):
    return q

@app.get("/items")
def read_item(q: str | None = Depends(get_query)):
    return {"q": q}
```

---

## 5. How does FastAPI handle request validation?
FastAPI uses Pydantic models to validate request bodies and query parameters automatically.

```python
from pydantic import BaseModel
from fastapi import FastAPI

app = FastAPI()

class UserCreate(BaseModel):
    name: str
    age: int

@app.post("/users")
def create_user(user: UserCreate):
    return {"message": f"Hello {user.name}"}
```

---

## 6. What is a Pydantic model?
A Pydantic model defines the expected structure of data and validates it automatically.

```python
from pydantic import BaseModel

class User(BaseModel):
    id: int
    name: str
```

---

## 7. How do you handle errors in FastAPI?
FastAPI allows you to raise `HTTPException` or use exception handlers for centralized error handling.

```python
from fastapi import FastAPI, HTTPException

app = FastAPI()

@app.get("/items/{item_id}")
def read_item(item_id: int):
    if item_id != 1:
        raise HTTPException(status_code=404, detail="Item not found")
    return {"item_id": item_id}
```

---

## 8. What is the difference between `async def` and `def` in FastAPI?
`async def` is used for asynchronous operations and is ideal for I/O-bound tasks like database access or HTTP calls. `def` is synchronous and simpler for blocking operations.

---

## 9. How do you connect FastAPI with a database?
You typically use an ORM such as SQLAlchemy or an async database driver. The service layer usually handles the database logic while the route layer remains thin.

---

## 10. What is the role of routers in FastAPI?
Routers help organize endpoints into separate modules and keep the application maintainable as it grows.

```python
from fastapi import APIRouter

router = APIRouter()

@router.get("/users")
def get_users():
    return [{"id": 1, "name": "Ankit"}]
```

---

## 11. How would you structure a production FastAPI application?
A senior engineer usually structures the project with separate layers:
- routers
- schemas
- services
- models
- repositories
- configuration
- tests

This separation improves maintainability and testability.

---

## 12. What are the benefits of using async programming in FastAPI?
Async programming improves scalability for I/O-bound workloads such as database queries, network calls, and file operations.

---

## 13. How do you secure a FastAPI API?
Common security practices include:
- authentication and authorization
- JWT-based auth
- rate limiting
- input validation
- environment-based configuration
- secure headers

---

## 14. How do you implement authentication in FastAPI?
Authentication is often implemented with JWT tokens and dependency injection. A common pattern is to create an auth dependency that validates the token before access is granted.

---

## 15. How do you add logging in FastAPI?
FastAPI can use Python logging or structured logging libraries. Logging should capture request metadata, response errors, and service-level warnings.

---

## 16. What is OpenAPI in FastAPI?
FastAPI automatically generates OpenAPI documentation, which is useful for API consumers and internal teams.

---

## 17. How do you test FastAPI endpoints?
FastAPI applications are commonly tested with `pytest` and `TestClient`.

```python
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_health():
    response = client.get("/health")
    assert response.status_code == 200
```

## 18. How would you deploy a FastAPI service?
FastAPI services are often deployed using:
- Uvicorn
- Gunicorn
- Docker
- Kubernetes
- cloud hosting platforms

---

## 19. What is the difference between FastAPI and Flask?
FastAPI provides built-in async support, automatic validation, and better API ergonomics, while Flask is more minimal and flexible but requires more manual work for validation and structure.

---

## 20. What is the difference between FastAPI and Django REST Framework?
FastAPI is lightweight and async-first, while Django REST Framework is more opinionated and integrated with the Django ecosystem.

---

## 21. How do you handle environment configuration in FastAPI?
Environment variables and config loaders such as `python-dotenv` are commonly used to keep secrets and environment-specific values out of code.

---

## 22. How do you make a FastAPI app production-ready?
A senior engineer would focus on:
- proper error handling
- observability
- testing
- validation
- secure config
- performance tuning
- containerization

---

## 23. How do you design scalable FastAPI services?
Scalability usually comes from:
- stateless services
- caching
- background workers
- database optimization
- load balancing
- service decomposition

---

## 24. What is the main advantage of using Pydantic with FastAPI?
It makes input validation explicit, reusable, and easy to maintain.

---

## 25. How would you explain FastAPI in an interview?
I would say FastAPI is a high-performance Python framework for building modern APIs with strong validation, async support, and great developer productivity.
