# Advanced Python Concepts

## 18. What are iterators and generators?
An iterator is an object that can be iterated over, while a generator produces values lazily.

```python
def count_up(n):
    for i in range(n):
        yield i
```

---

## 19. What is list comprehension?
List comprehension is a concise way to create lists.

```python
squares = [x * x for x in range(5)]
```

---

## 20. What is a decorator?
A decorator modifies or enhances a function without changing its structure.

```python
def decorator(fn):
    def wrapper(*args, **kwargs):
        print("Before")
        return fn(*args, **kwargs)
    return wrapper
```

## 21. What is the difference between shallow copy and deep copy?
A shallow copy copies the top-level object, while a deep copy copies nested objects as well.
